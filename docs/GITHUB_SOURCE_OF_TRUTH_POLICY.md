# Repository source-of-truth policy
All public product requirements, storylines, review criteria and Claude instructions must be self-contained in this repository. Do not link to Notion or other private workspaces from GitHub README, docs, issue templates or public issues. Convert approved material into reviewed Markdown with source citations and no private user information.

## Editing checklist
- Before adding a reference, prefer a relative path to a committed document.
- Quran.com and Sunnah.com citations are allowed and should be canonical; external public legal or cultural sources may be cited with provenance.
- Do not publish private workspace URLs, collaborator details, internal financials, access tokens or personal stories.
- Do not claim a document is reviewed merely because it was copied from a planning workspace.
- When an external source is inaccessible, mark its claim pending instead of guessing.
- For every new storyline, update the local world bible/branch atlas and issue acceptance criteria.
- Review GitHub content for forbidden private-workspace links and personal information before merging.

## Claude handoff
Read CLAUDE.md and the branch-continuity-audit skill. Keep changes docs-only until a separate implementation issue is authorized. No gameplay logic in this phase.
