## Review distinctions
Text checked != context reviewed != legal/fiqh application approved != public-release approved. When disputed or unknown, use 'Learn more' and neutral warnings instead of 'HARAM'. No scoring of divine reward, worship or salvation.

## Required negative tests
Source URL missing; citation references wrong verse; hadith grade absent where needed; claim unsupported by context; conflicting legal-school rulings; changed source or reviewer decision; missing translation rights; school-specific ruling shown as universal; accidental event labeled sin; child NPC subjected to harmful scenario. All block publication or require correction.
