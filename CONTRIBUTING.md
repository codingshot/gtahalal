# Contributing to Dunya

Welcome! Contributors can help with game logic, Three.js scenes, 3D assets, city research, accessibility, translation, source review and QA.

## Start
1. Read `README.md`, `AGENTS.md`, and `CODE_OF_CONDUCT.md`.
2. Open or claim a scoped issue; discuss larger architectural changes first.
3. Create a branch, make focused commits, add tests and documentation.
4. Run lint, typecheck, test and build. Submit a PR with screenshots, source and asset provenance.

## Content gate
Religious missions require exact Quran.com/Sunnah.com URLs, context, grading where relevant and qualified reviewer approval before publication. Cultural and sacred-site representation requires local review. No offensive or illicit gameplay.

## Privacy and licensing
Never commit personal data, credentials or copyrighted game assets. Use original or licensed assets with attribution. Code licensing is pending community approval; do not assume third-party contributions are automatically relicensable.
