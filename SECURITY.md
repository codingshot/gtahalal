# Security policy

## Reporting
Do not disclose exploitable vulnerabilities, credentials or private user data in public issues. Use [GitHub private vulnerability reporting](https://github.com/codingshot/gtahalal/security/advisories/new) if enabled; otherwise contact repository maintainers through an appropriate private channel without posting secrets publicly. Do not send real passwords, tokens, passports or personal information as test data.

## Scope
Security reviews should consider public contribution supply chain, dependencies, untrusted story content, future chat/moderation, privacy, payment/charity providers and uploaded media. No live payments, identity checks or sensitive religious behavior analytics should be introduced without separate approval.

## Supported releases
No supported production game release is declared at this stage. Security fixes and policies will evolve before launch.
